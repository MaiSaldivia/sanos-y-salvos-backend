# bff

Microservicio del proyecto **Sanos y Salvos** — Fullstack III DuocUC 2026

## Instalación

```bash
cd microservicios/bff
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

## Configuración

Editar el archivo `.env` con los datos de tu MySQL/XAMPP.

## Pruebas unitarias

```bash
npm test
```

## Health check

GET http://localhost:$(PORT)/health

Ver README.md principal del proyecto para instrucciones completas.
